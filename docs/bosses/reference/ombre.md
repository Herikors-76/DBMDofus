# Ombre

Pyramide d'Ombre · niveau 190 · position [6,13 (Dimension Obscure)] · PV 11000-17000

Fiche de référence : `bosses/reference/ombre.yaml` · fiabilité : **source_unique**

## États
- Invulnérable tant que la Silhouette n'est pas dans le glyphe du Globilum

## Sorts
- **Pénombre** : Augmente Distorsion ; +2 PM au lanceur et aux alliés à 2 cases
- **Distorsion** : Gros dégâts eau en cercle de rayon 3 autour de lui
- **Liaison** : 2 à 7 PO, attire de 3 et avance de 3 ; dégâts neutres cumulatifs

## Mécaniques
- **Vulnérabilité** (Silhouette dans le glyphe) : Ombre vulnérable, sauf s'il est lui-même dans le glyphe
- **Glyphe du Globilum** (fin du tour du Globilum) : Glyphe autour du Globilum où placer la Silhouette
- **Silhouette** (chaque tour) : Déplaçable une seule fois par tour

## Stratégie
- Tuer les sbires d'abord, le Sombléro en priorité
- Tacleur ou placeurs pour garder la Silhouette dans le glyphe (Xélor, Sacrieur, Écaflip)
- Rester loin d'Ombre

## Alertes
- [important] Silhouette dans le nouveau glyphe
- [important] Silhouette : un seul déplacement par tour
- [info] Gardez Ombre à distance (Liaison se cumule)
