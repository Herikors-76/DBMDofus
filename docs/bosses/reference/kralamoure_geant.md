# Kralamoure Géant

Antre du Kralamoure Géant · niveau 180 · position [-60,-8]

Fiche de référence : `bosses/reference/kralamoure_geant.yaml` · fiabilité : **source_unique**

## États
- 900 % de résistances dans tous les éléments

## Sorts
- **Kracheau immobilisant** : Vol de vie, 700 à 1 500, affaiblit
- **Kraken** : +200 PV par tour
- **Vulnérabilité de la Tourbière** : Retire ses résistances ; vous gagnez +2 PM, 63 PO et 8 000 dégâts fixes pendant 2 tours

## Mécaniques
- **Tentacules** (frapper le boss dans l'élément de chaque tentacule) : Invoque les tentacules eau, feu, terre, air
- **Vulnérabilité** (les 4 tentacules lancent leur sort le MÊME tour) : Active Vulnérabilité de la Tourbière

## Stratégie
- Retenir les tentacules (Pandawasta, Arbres) et les placer un par un
- Enutrof quasi indispensable (portée, lignes de vue)

## Alertes
- [critique] Les 4 sorts de tentacules dans le même tour
- [important] Immobilisez le Tentacule Primaire
