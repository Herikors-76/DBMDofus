# Koumiho

Demeure des Esprits · niveau 170 · position [39,-44] · PV 8800-13000

Fiche de référence : `bosses/reference/koumiho.yaml` · fiabilité : **source_unique**

## États
- Invulnérable tant que ses 2 Kitsounebis ne meurent pas le même tour

## Sorts
- **Hoshi no tama** : Soigne ses alliés de 20 % PV max
- **No raj** : -PO, -PM, -intelligence 1 tour
- **Aura des Kitsounebi** : Feu, air, terre à tous les adversaires
- **Retraite** : Tous les 6 tours : invisible + Pacifiste, puis soin + bouclier

## Mécaniques
- **Kitsounebis invisibles** (dès le tour 2) : Visibles seulement dans la zone de la Lanterne des Spiritueurs
- **Réinvocation** (Kitsounebi tué sans son jumeau) : Koumiho le fait revenir

## Stratégie

- Repérer les Kitsounebis (Lanterne) et les tuer le même tour
