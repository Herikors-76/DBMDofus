# Ilyzaelle

Belvédère d'Ilyzaelle · niveau 200 · position [-61,-79 (Château du Comte)] · PV 42000-60000

Fiche de référence : `bosses/reference/ilyzaelle.yaml` · fiabilité : **source_unique**

## Sorts
- **Vers les ténèbres** : Attire les ennemis de 10 cases ; tous les 3 tours dès le tour 2
- **Lance de l'effroi** : Feu + Pacifiste 1 tour
- **Hantâme** : Téléportation, feu + 40 % d'érosion en cercle de 2

## Mécaniques
- **Libération** (chaque -25 % de PV max) : Se libère des Brulâmes et passe dans votre camp 2 tours ; pose un glyphe +400 % de dégâts finaux (les Brulâmes qui y entrent perdent ~50 % PV)
- **Retour** (après 2 tours) : Repasse sous contrôle des Brulâmes, invulnérable et immobile son 1er tour
- **Victoire** (sous 50 % + 2 tours dans votre camp) : Elle tue les Brulâmes restants, fin du combat

## Stratégie
- Exploiter son glyphe quand elle est de votre côté
- Se cacher derrière un obstacle contre l'attraction
- Rester loin des Brulâmes

## Alertes
- [important] Attraction de 10 : derrière un obstacle
- [important] Retirez 25 % de plus pour la libérer
- [critique] Tenez 2 tours avec Ilyzaelle dans votre camp
