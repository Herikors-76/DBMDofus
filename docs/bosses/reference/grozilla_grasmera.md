# Grozilla et Grasmera

Cratère Minus (tous niveaux) · niveau 50 · position [-51,40 (Vulkania)] · PV 16000-23000 (chacun, version normale)

Fiche de référence : `bosses/reference/grozilla_grasmera.yaml` · fiabilité : **a_verifier**

## Sorts
- **Atomes Crochus** : Tous les 5 tours dès le tour 5 : si les boss sont à plus de 2 cases l'un de l'autre, l'équipe est anéantie
- **Fission** : Si l'un meurt, l'autre tue un adversaire par tour

## Mécaniques
- **Mort simultanée** (fin du combat) : Les deux boss doivent mourir le même tour

## Stratégie
- Les rapprocher aux tours 6, 11, 16…
- Les tuer le même tour

## Alertes
- [critique] Atomes Crochus : boss à 2 cases ou moins l'un de l'autre !
- [critique] Tuez l'autre CE tour (Fission)
