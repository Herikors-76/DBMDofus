# Chaloeil

Défi du Chaloeil · niveau 200 · position [-9,-22 (Écaflipus)] · PV 15000-22000

Fiche de référence : `bosses/reference/chaloeil.yaml` · fiabilité : **source_unique**

## États
- Invulnérable jusqu'au tour 21

## Sorts
- **Toilette Écaflip** : Gros dégâts eau, 1 à 2 PO en ligne, poussée de 3, -4 PM
- **Farce et Attrape** : Gros dégâts terre, 1 à 6 PO, échange de position + Pesanteur, 3 fois par tour
- **Gros Yeux** : Tous les 3 tours : bonus selon la case (1 : +200 esquive PM, 2 : +5 PO, 3 : Indéplaçable, 4 : +3 PM, 5 : soin, 6 : +600 puissance)

## Mécaniques
- **Dés et glyphes** (fin du tour du Chaloeil) : Dés (obstacles) et glyphes blancs (soin) sur les cases de même numéro
- **Effet de case** (monstre sur une case de même valeur qu'un perso) : 200 à 300 neutre + 20 % d'érosion au perso
- **Vagues** (tous les 5 tours) : 5 vagues ; la suivante arrive dès que la précédente est vidée

## Stratégie
- Lui retirer des PM, le bloquer dans un coin
- Se soigner sur les glyphes blancs

## Alertes
- [critique] Invulnérable jusqu'au tour 21
- [critique] Tour 21 : le Chaloeil est vulnérable !
- [important] Gros Yeux : vérifiez les cases
- [info] Nouvelle vague
