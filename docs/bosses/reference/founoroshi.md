# Founoroshi

Fabrique de Foux d'Artifice · niveau 140 · position [14,-32] · PV 4200-6100

Fiche de référence : `bosses/reference/founoroshi.yaml` · fiabilité : **source_unique**

## États
- Invulnérable tant que les Feux de Bengale sont allumés

## Sorts
- **Fumée alourdissante** : Phase invulnérable
- **Lanternes volantes** : Phase invulnérable
- **Pétards volants** : Phase vulnérable

## Mécaniques
- **Extinction des Feux** (marcher sur un glyphe gris) : Puis marcher sur un Feu l'éteint ; 8 Feux éteints = monstres vulnérables
- **Lanternes** (tous les 4 tours) : Si une lanterne atteint un Feu, l'équipe meurt

## Stratégie
- Éteindre un Feu dès le tour 1
- Résister aux retraits PA/PM (Boumbardier)

## Alertes
- [critique] Lanternes : empêchez-les d'atteindre un Feu !
- [info] Glyphe gris → Feu
