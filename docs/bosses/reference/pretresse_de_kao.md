# Prêtresse de Kao

Temple du Dieu Kao · niveau 190 · position [-1,-10 (Île de Pwâk)] · PV 18000

Fiche de référence : `bosses/reference/pretresse_de_kao.yaml` · fiabilité : **source_unique**

## États
- Invulnérable tant que l'état chiffré n'est pas à 3

## Sorts
- **Cloches du Kao** : Neutre à tous les adversaires un tour sur deux ; +50 par entité Chocolathée
- **Equador** : Cercle inversé de 6 : soigne de 10 % et booste ses alliés
- **Commerce Inéquitable** : Neutre à distance, 3 fois par tour, vole 2 PM
- **Spatule Tranche-Gourmands** : Air en ligne, -50 fuite 1 tour

## Mécaniques
- **Compteur Éclat Kao** (mort d'un Éclat Kao) : +1 état chiffré ; à 3, vulnérable jusqu'à la fin
- **Dégâts croissants** (chaque niveau du compteur) : +52 % / +74 % / +99 % de dégâts finaux

## Stratégie
- Tuer l'Éclat Kao pendant son 1er tour
- Un seul perso en Chocolathée
- Tuer les 3 accompagnants avant les Éclats

## Alertes
- [important] Cloches du Kao : tout le monde prend
- [critique] Prêtresse vulnérable, +99 % de dégâts
