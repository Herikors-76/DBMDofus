# Kolosso

Cavernes du Kolosso · niveau 190 · position [-61,-69] · PV 8000-12000

Fiche de référence : `bosses/reference/kolosso.yaml` · fiabilité : **source_unique**

## États
- Invulnérable sauf après dégâts d'une invocation

## Sorts
- **Razepoutine** : Depuis le contact, gros dégâts terre en cône infini
- **Baïkal** : +50 dommages
- **Illyana** : Sur un allié : attire de 2 et soigne

## Mécaniques
- **Vulnérabilité** (dégâts d'une invocation) : Vulnérable jusqu'au prochain tour de cette invocation
- **Professeur Xa** (en vie) : Bloque les soins classiques (sauf % de vitalité)

## Stratégie
- Une invocation qui frappe le Kolosso
- Le tenir à l'écart pendant qu'on tue les autres
- Jamais derrière un allié dans l'axe du cône

## Alertes
- [critique] Cône infini : pas derrière un allié
- [important] Frappez-le avec une invocation
