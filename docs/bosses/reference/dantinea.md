# Dantinéa

Palais de Dantinéa · niveau 200 · position [19,26] · PV 18000-26000

Fiche de référence : `bosses/reference/dantinea.yaml` · fiabilité : **source_unique**

## Sorts
- **Siphon d'Âme** : Neutre en vol de vie, portée 3 fixe, ligne de vue
- **Danse Tentaculaire** : Terre en zone autour d'elle
- **Cooquillation** : Échange avec un coquillage, portée 6, tous les 2 tours (dès le tour 2)

## Mécaniques
- **Coquillages** (tous les 5 tours) : 1 coquillage de 1 000 PV par perso (dégâts reçus /2) ; tant qu'ils vivent, les monstres ne prennent pas de dégâts
- **Pénalité** (chaque tour avec un coquillage vivant) : -1 PM cumulable
- **Exécution** (coquillage encore vivant à la réinvocation) : Le perso est tué

## Stratégie
- Rester loin de Dantinéa
- Tuer TOUS les coquillages avant la réinvocation (y compris ceux des alliés)
- Choisir son placement de départ selon le côté d'invocation

## Alertes
- [critique] Réinvocation : tuez tous vos coquillages !
- [important] Coquillage vivant = -1 PM
