# Guerre

Trône de Sang · niveau 200 · position [4,-2 (Blessure de Guerre)] · PV 19000-24000

Fiche de référence : `bosses/reference/guerre.yaml` · fiabilité : **source_unique**

## États
- Invulnérable
- Brave

## Sorts
- **Bravoure** : Sur un monstre : tacle, fuite, PM et Brave. Sur un joueur : Pesanteur + Insoignable
- **Lynchage** : Contact, 1 fois par tour : feu puis poison 2 tours
- **Impact** : 1 à 3 PO sans ligne de vue, si cible Brave : feu + 25 % d'érosion 2 tours
- **Célérité** : Échange avec l'arme la plus proche puis glyphe (~700 feu)
- **Magmaléfice** : 1 à 6 PO, zone de 2 cases, feu
- **Martyre** : Contact, si cible non Brave : terre, poison feu possible

## Mécaniques
- **Armes invoquées** (après les monstres, tous les -20 % de PV) : Épée (-20 %), Marteau (-40 %), Hache (-60 %, 1 000 bouclier tous les 2 tours), Morgenstern (-80 %)
- **Pacifiste** (1re attaque sur Guerre) : Pacifiste pour l'attaquant

## Stratégie
- Repousser Guerre pendant qu'on tue les monstres
- Gros dégâts en une seule attaque mono-ligne

## Alertes
- [important] Nouvelle arme : sortez de sa zone
- [critique] Ne marchez pas sur le glyphe
