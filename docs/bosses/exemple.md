# Gardien d'exemple (boss fictif)

Fichier de données : `bosses/exemple.yaml`. Sert de modèle : aucune mécanique réelle.

## Phases
- **Phase 1** : tours 1 à 5.
- **Phase 2 (enragé)** : à partir du tour 6.
- **Phase 3** : déclenchée à la main (Ctrl+Alt+P).

## Mécaniques
| Mécanique | Quand | Alerte |
|---|---|---|
| Onde de choc | tous les 3 tours dès le tour 3, préavis 1 tour | critique |
| Bouclier | tours 2 et 5, phase 1 | important |
| Invocations | tous les 2 tours dès le tour 6, phase 2 | info |

## Stratégie
Placement en arc de cercle, soigneur derrière. Garder un sort de fuite pour l'onde de choc.
