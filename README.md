# DBMDofus

Alertes de mécaniques de boss pour Dofus 3 (guilde No Try No Gain). Overlay externe et passif :
capture d'écran + OCR et raccourcis clavier, conforme aux CGU Ankama (aucune lecture mémoire,
aucun paquet, aucune action en jeu).

```
pip install -r requirements.txt
python -m dbmdofus
```

Voir CARTE.md (carte du dépôt) et REPRISE.md (état et prochaines étapes).
